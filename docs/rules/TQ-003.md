# TQ-003: Tool Parameters Described

- **Category:** `tool-quality`
- **Default Severity:** `warning`
- **Penalty Points:** 5
- **Scope:** Tool-level
- **Specification:** [W3C WebMCP Parameter Documentation](https://webmachinelearning.github.io/webmcp/)

---

## Overview

When generating function-calling JSON payloads, LLMs inspect each individual parameter definition inside `inputSchema.properties`. A parameter definition that lacks a `description` field leaves the agent uncertain of the parameter's expected format, units, or semantics, drastically increasing the likelihood of hallucinated arguments.

---

## Failure Condition

This rule flags any property declared inside `inputSchema.properties` that does not include an informative `description` string.

### ❌ Non-Compliant Example

```javascript
navigator.modelContext.registerTool({
  name: "book_flight",
  description: "Books an airline ticket for a passenger.",
  inputSchema: {
    type: "object",
    properties: {
      origin: { type: "string" }, // Missing description!
      destination: { type: "string" }, // Missing description!
      date: { type: "string" } // Missing format & description!
    },
    required: ["origin", "destination", "date"]
  }
});
```

---

## Remediation

Add a descriptive string to every parameter in `inputSchema.properties` explaining its expected format, valid range or values, and intent.

### ✅ Compliant Example

```javascript
navigator.modelContext.registerTool({
  name: "book_flight",
  description: "Books an airline ticket for a passenger.",
  inputSchema: {
    type: "object",
    properties: {
      origin: {
        type: "string",
        description: "Three-letter IATA departure airport code (e.g. SFO, JFK)."
      },
      destination: {
        type: "string",
        description: "Three-letter IATA arrival airport code (e.g. LHR, HND)."
      },
      date: {
        type: "string",
        description: "Departure date in ISO 8601 format (YYYY-MM-DD)."
      }
    },
    required: ["origin", "destination", "date"]
  }
});
```
