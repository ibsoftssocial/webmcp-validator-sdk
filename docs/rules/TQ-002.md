# TQ-002: Tool Description Required

- **Category:** `tool-quality`
- **Default Severity:** `error` (if missing) / `warning` (if placeholder or < 10 characters)
- **Penalty Points:** 10
- **Scope:** Tool-level
- **Specification:** [W3C WebMCP Tool Descriptions](https://webmachinelearning.github.io/webmcp/)

---

## Overview

AI agents and LLMs select which tool to call based primarily on the semantic meaning articulated in the tool's `description`. A tool without a descriptive summary is virtually invisible or unpredictably misused by calling models.

This rule validates that:
1. Every registered tool includes a non-empty `description` string.
2. The description does not use generic placeholder terms (such as `"test"`, `"demo"`, `"does something"`, `"todo"`).
3. The description is of sufficient length (at least 10 characters) to provide meaningful context to LLMs.

---

## Failure Conditions

1. **Missing Description (`error`):** The `description` field is undefined, null, or empty string.
2. **Placeholder Description (`warning`):** Contains meaningless strings like `"test"`, `"tool"`, `"placeholder"`.
3. **Excessively Brief (`warning`):** Contains fewer than 10 characters (e.g., `"search"`).

### ❌ Non-Compliant Examples

```javascript
// Missing description completely (Error)
navigator.modelContext.registerTool({
  name: "delete_item",
  inputSchema: { type: "object" }
});

// Generic placeholder (Warning)
navigator.modelContext.registerTool({
  name: "get_weather",
  description: "test",
  inputSchema: { type: "object" }
});

// Excessively brief (Warning)
navigator.modelContext.registerTool({
  name: "checkout",
  description: "pays cart",
  inputSchema: { type: "object" }
});
```

---

## Remediation

Provide a clear, detailed sentence explaining what action the tool performs, what input parameters are expected, and what results or side-effects occur.

### ✅ Compliant Example

```javascript
navigator.modelContext.registerTool({
  name: "get_current_weather",
  description: "Fetches current temperature, humidity, and atmospheric conditions for a given city or geographic coordinates.",
  inputSchema: {
    type: "object",
    properties: {
      location: { type: "string", description: "City name or zip code" }
    },
    required: ["location"]
  }
});
```
