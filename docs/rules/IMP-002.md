# IMP-002: Unique Tool Identifiers

- **Category:** `implementation`
- **Default Severity:** `error`
- **Penalty Points:** 10
- **Scope:** Page-level
- **Specification:** [W3C WebMCP Unique Identifiers](https://webmachinelearning.github.io/webmcp/)

---

## Overview

Tool names must be unique within a web page across all registered sources (imperative JavaScript, declarative HTML forms, and linked manifests). If multiple tools share the same name, AI reasoning models face ambiguity when deciding which function to call, leading to unpredictable tool invocation or runtime collision errors.

---

## Failure Condition

This rule triggers with severity `error` whenever two or more tools on the same page share an identical `name` identifier.

### ❌ Non-Compliant Example

Two different components or forms on the page register a tool named `submit_feedback`:

```html
<!-- Form 1: Declarative -->
<form toolname="submit_feedback" tooldescription="Submits rating feedback">
  <input name="rating" type="number" />
</form>

<!-- Script 2: Imperative -->
<script>
navigator.modelContext.registerTool({
  name: "submit_feedback",
  description: "Submits text feedback ticket",
  inputSchema: { type: "object", properties: { ticketText: { type: "string" } } }
});
</script>
```

---

## Remediation

Ensure every tool registered on the page has a distinct and unambiguous name identifier. Use domain prefixes or descriptive actions if multiple related tools exist.

### ✅ Compliant Example

```html
<!-- Form 1: Scoped rating submission -->
<form toolname="submit_star_rating" tooldescription="Submits numeric rating for current page">
  <input name="rating" type="number" />
</form>

<!-- Script 2: Scoped support ticket submission -->
<script>
navigator.modelContext.registerTool({
  name: "submit_support_ticket",
  description: "Submits detailed support ticket to customer helpdesk",
  inputSchema: {
    type: "object",
    properties: {
      ticketText: { type: "string", description: "Body of the support request" }
    },
    required: ["ticketText"]
  }
});
</script>
```
