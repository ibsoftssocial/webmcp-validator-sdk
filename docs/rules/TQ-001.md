# TQ-001: Tool Name Format

- **Category:** `tool-quality`
- **Default Severity:** `error` (for illegal characters or excess length) / `warning` (for casing)
- **Penalty Points:** 10
- **Scope:** Tool-level
- **Specification:** [W3C WebMCP Tool Naming Conventions](https://webmachinelearning.github.io/webmcp/)

---

## Overview

Tool names serve as programmatic identifiers used directly by Large Language Models in tool-call schemas. They must follow standard syntax:
- Must start with an ASCII letter (`a-z` or `A-Z`).
- Must only contain alphanumeric characters, underscores (`_`), hyphens (`-`), or dots (`.`).
- Must not exceed 64 characters in total length.
- Standard convention requires lowercase `snake_case` (e.g. `add_to_cart` instead of `AddToCart`).

---

## Failure Conditions

1. **Length Exceeded (`error`):** The tool name is longer than 64 characters.
2. **Invalid Characters (`error`):** Contains whitespace, punctuation symbols like `@`, `#`, `$`, `/`, or starts with a digit/symbol.
3. **Casing Inconsistency (`warning`):** Uses camelCase or PascalCase instead of idiomatic `snake_case`.

### ❌ Non-Compliant Examples

```javascript
// Too long (> 64 characters)
navigator.modelContext.registerTool({
  name: "a_very_long_tool_name_that_exceeds_the_standard_maximum_length_limit_of_64_characters_allowed",
  ...
});

// Invalid characters (spaces and symbols)
navigator.modelContext.registerTool({
  name: "search & filter #products",
  ...
});

// PascalCase or camelCase (Triggers warning with suggested snake_case)
navigator.modelContext.registerTool({
  name: "getUserOrderHistory",
  ...
});
```

---

## Remediation

Rename the tool to follow lowercase `snake_case` conventions, under 64 characters.

### ✅ Compliant Examples

```javascript
// Concise, valid snake_case identifiers
navigator.modelContext.registerTool({
  name: "get_user_order_history",
  ...
});

navigator.modelContext.registerTool({
  name: "search_products",
  ...
});
```
