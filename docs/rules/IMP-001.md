# IMP-001: WebMCP API Presence

- **Category:** `implementation`
- **Default Severity:** `error`
- **Penalty Points:** 100
- **Scope:** Page-level
- **Specification:** [W3C WebMCP Overview Draft](https://webmachinelearning.github.io/webmcp/)

---

## Overview

Validates that the audited web page provides a detectable WebMCP implementation. An agent cannot interact with a website programmatically if no WebMCP surface is exposed.

WebMCP implementations can be detected via:
1. **Imperative JavaScript API:** `window.navigator.modelContext` or `document.modelContext`.
2. **Declarative HTML Markup:** Forms or buttons declaring `toolname`, `tooldescription`, or `toolaction`.
3. **Discovery Manifest:** A `<link rel="model-context" href="/.well-known/mcp.json">` tag in HTML `<head>` or a hosted manifest at `/.well-known/webmcp`.

---

## Failure Condition

This rule fails with severity `error` if none of the above WebMCP interfaces are detected on the scanned page.

### ❌ Non-Compliant Example

A standard website that offers only traditional DOM elements without registering any WebMCP tools or manifest:

```html
<!DOCTYPE html>
<html>
<head>
  <title>Standard Store</title>
</head>
<body>
  <h1>Welcome to Store</h1>
  <!-- No WebMCP tools, no modelContext API, no manifest link -->
</body>
</html>
```

---

## Remediation

Expose tools either through imperative registration in client JavaScript, declarative markup on existing forms, or link a discovery manifest.

### ✅ Compliant Examples

#### Option 1: Imperative Registration (JavaScript)
```javascript
if ('modelContext' in navigator) {
  navigator.modelContext.registerTool({
    name: 'search_catalog',
    description: 'Searches the product store catalog by query keyword.',
    inputSchema: {
      type: 'object',
      properties: {
        query: { type: 'string', description: 'Search keywords' }
      },
      required: ['query']
    },
    async execute({ query }) {
      const results = await fetch(`/api/search?q=${encodeURIComponent(query)}`);
      return results.json();
    }
  });
}
```

#### Option 2: Declarative Form Markup (HTML)
```html
<form
  action="/search"
  method="GET"
  toolname="search_catalog"
  tooldescription="Searches the product store catalog by query keyword."
  toolaction="search_products"
>
  <input type="text" name="query" placeholder="Search..." required />
  <button type="submit">Search</button>
</form>
```

#### Option 3: Manifest Link in `<head>`
```html
<head>
  <link rel="model-context" type="application/json" href="/.well-known/mcp.json" />
</head>
```
