# BP-001: Valid Input Schema

- **Category:** `best-practices`
- **Default Severity:** `error`
- **Penalty Points:** 10
- **Scope:** Tool-level
- **Specification:** [W3C WebMCP Input Schema Definition](https://webmachinelearning.github.io/webmcp/)

---

## Overview

The WebMCP specification requires that a tool's `inputSchema` conforms to JSON Schema Draft-07 (or compatible subset). Specifically:
1. `inputSchema` must be an object.
2. `inputSchema.type` must be strictly set to `"object"`.
3. Any field listed in the `required` array must actually exist in `properties`.
4. Every property defined in `properties` must declare a valid `type` (e.g., `"string"`, `"number"`, `"boolean"`, `"array"`, `"object"`).

Violations cause client-side and model-side validation failures or crash calling tool runners.

---

## Failure Conditions

1. `inputSchema` is missing.
2. `inputSchema.type` is not `"object"` (e.g. `"string"` or `"array"`).
3. A field in `inputSchema.required` is missing from `inputSchema.properties`.
4. A property in `inputSchema.properties` lacks a `type` declaration.

### ❌ Non-Compliant Examples

```javascript
// Missing inputSchema
navigator.modelContext.registerTool({
  name: "get_status",
  description: "Gets system status"
  // inputSchema missing!
});

// Non-object type
navigator.modelContext.registerTool({
  name: "echo_string",
  description: "Echoes input string",
  inputSchema: { type: "string" } // Must be "object"!
});

// Required property mismatch
navigator.modelContext.registerTool({
  name: "update_profile",
  description: "Updates user profile info",
  inputSchema: {
    type: "object",
    properties: {
      bio: { type: "string", description: "Biography" }
    },
    required: ["userId", "bio"] // userId is not defined in properties!
  }
});
```

---

## Remediation

Ensure `type: "object"` is declared, all required fields exist in `properties`, and each property declares its data type.

### ✅ Compliant Example

```javascript
navigator.modelContext.registerTool({
  name: "update_profile",
  description: "Updates user profile info",
  inputSchema: {
    type: "object",
    properties: {
      userId: {
        type: "string",
        description: "The unique UUID of the target user profile."
      },
      bio: {
        type: "string",
        description: "Updated biography text (max 280 characters)."
      }
    },
    required: ["userId", "bio"]
  }
});
```
