WebMCP Developer Guide & Toolkit Reference

The definitive guide to scanning, validating, and scoring WebMCP AI agent capabilities on modern websites using the official SDK and CLI.

🌐 1. Overview & Core Concept

The W3C WebMCP (Web Model Context Protocol) standard empowers web applications to expose structured tools and actions directly to browser-based AI agents (such as Google Gemini, Claude, and OpenAI Operator).

📄
Declarative Forms
HTML forms annotated with toolname, tooldescription, and toolaction attributes for zero-JS agent interactions.
⚡
Imperative JS API
Runtime registration via navigator.modelContext.registerTool() for rich client-side SPAs.
🧭
Agent Discovery
Machine-readable manifests (/.well-known/webmcp), /llms.txt, and crawler directives in /robots.txt.
🧠
Chrome Built-in AI
Client-side Gemini Nano Prompt API support via window.ai.languageModel for local inference.

🏗️ 2. Ecosystem Architecture

The WebMCP Validator operates as a 4-stage pipeline running on headless Chromium:

[Target URL]
  ↳ 1. Discovery Engine: Headless Playwright scan (DOM forms, navigator.modelContext, manifests, robots.txt, llms.txt)
  ↳ 2. Linter Engine: 11 Built-in validation rules (IMP-001, TQ-001, BP-001, SEC-001, DISC-001, etc.)
  ↳ 3. Scorer Model: 100-point rubric across 6 categories mapped to letter grades (A through F)
  ↳ 4. Exporter Engine: Terminal tables, standalone HTML, JSON, Markdown, SARIF 2.1.0, and JUnit XML

🚀 3. Quick Start (60 Seconds)

Run your first scan immediately without installing any packages:

Terminal (npx zero-install) 
npx webmcp-validator-cli scan https://webmcpworld.com

Or install the programmatic SDK in your project:

Terminal 
npm install webmcp-validator-sdk
audit.js (ESM) 
import { WebMCPValidator } from 'webmcp-validator-sdk';

const report = await WebMCPValidator.audit('https://webmcpworld.com');

console.log(`Score: ${report.overallScore}/100 (Grade ${report.grade})`);
console.log(`Tools Found: ${report.toolCount}`);
console.log(`Passed: ${report.passed}`);

🛠️ 4. CLI Guide (`webmcp-validator-cli`)

Global Installation

To use short command aliases (webmcp or webmcp-validator) system-wide:

Terminal 
npm install -g webmcp-validator-cli

Single URL Auditing (`scan`)

CLI Commands
# Interactive scan with pretty diagnostic terminal table
webmcp scan https://webmcpworld.com

# Audit local dev server with mobile viewport emulation
webmcp scan http://localhost:3000 --mobile

# Speed up scans by skipping image and media assets
webmcp scan https://example.com --block-media

# Set custom timeout (milliseconds)
webmcp scan https://example.com --timeout 30000

Batch & Sitemap Crawling (`batch`)

Batch Commands
# Audit multiple explicit URLs concurrently
webmcp batch https://example.com https://example.com/docs https://example.com/pricing

# Crawl an XML sitemap (up to 25 pages, 4 concurrent workers)
webmcp batch --sitemap https://example.com/sitemap.xml --concurrency 4 --limit 25

# Read URLs from a line-separated text file and save HTML report
webmcp batch -f urls.txt -o site-audit.html

Report Export Formats

Format Flag / Option Output Target Primary Use Case
pretty --format pretty stdout Interactive developer terminal feedback
html -o report.html File Standalone visual dashboard for stakeholders
json --format json stdout / File Programmatic CI/CD ingestion and scripting
markdown --format markdown stdout / File GitHub Pull Request summaries & descriptions
sarif -o results.sarif File GitHub Security Tab / CodeQL code scanning alerts
junit -o junit.xml File GitLab CI / CircleCI native test runner reporting

CI/CD Quality Gating (`--fail-under`)

Exit with status code 0 on success, or 1 if the AI readiness score fails to meet the threshold:

CI Threshold Enforcement
# Break build if score is below 80
webmcp scan https://example.com --fail-under 80

# Require Grade A (score >= 90) for production releases
webmcp scan https://example.com --fail-under 90

💻 5. Programmatic SDK Guide (`webmcp-validator-sdk`)

One-Line Audit (`WebMCPValidator.audit`)

TypeScript / JavaScript
import { WebMCPValidator } from 'webmcp-validator-sdk';

const report = await WebMCPValidator.audit('https://webmcpworld.com', {
  scanner: {
    headless: true,
    timeoutMs: 20000,
    blockMedia: true,
  },
  scorer: {
    passingScore: 80,
  },
});

console.log(`Grade: ${report.grade} (${report.overallScore}/100)`);
console.log(`Passed: ${report.passed}`);

Modular Step-by-Step Pipeline

For custom pipelines requiring custom pre-processing or AST introspection:

Modular Pipeline
import { WebMCPValidator } from 'webmcp-validator-sdk';

// 1. Scan target using headless Chromium
const detection = await WebMCPValidator.scan('https://webmcpworld.com');
console.log(`Discovered ${detection.tools.length} tool definitions`);

// 2. Evaluate against linter rules
const lintResult = await WebMCPValidator.lint(detection, {
  rules: ['IMP-001', 'TQ-001', 'SEC-001', 'SEC-002'],
});
console.log(`Errors: ${lintResult.summary.errors}`);

// 3. Calculate score & grade
const report = WebMCPValidator.score(detection, lintResult, {
  passingScore: 85,
});

// 4. Export report directly to disk
await WebMCPValidator.saveReport(report, './audit.html');

Batch & Sitemap Audits

Batch SDK
import { WebMCPValidator } from 'webmcp-validator-sdk';

// 1. Discover URLs from sitemap
const urls = await WebMCPValidator.crawlSitemap('https://webmcpworld.com/sitemap.xml', {
  maxUrls: 20,
});

// 2. Run batch audit with concurrency pooling
const result = await WebMCPValidator.batchAudit({
  urls,
  concurrency: 4,
  failUnder: 80,
});

console.log(`Average Score: ${result.averageScore} (Grade ${result.overallGrade})`);
await WebMCPValidator.saveBatchReport(result, './site-audit.html');

Key TypeScript Interfaces

Type Definitions
export interface WebMCPReadinessReport {
  url: string;
  timestamp: string;
  overallScore: number;     // 0 - 100
  grade: 'A' | 'B' | 'C' | 'D' | 'F';
  passed: boolean;
  toolCount: number;
  categories: Record;
  checklist: ChecklistItem[];
  lintSummary: LintSummary;
  tools: ToolDeclaration[];
  durationMs: number;
}

export type ReadinessCategory =
  | 'declarative'
  | 'infrastructure'
  | 'agent-access'
  | 'imperative'
  | 'discovery-manifest'
  | 'chrome-ai';

🍳 6. Production Integration Recipes

Recipe: GitHub Actions Automated PR Gating

Save as .github/workflows/webmcp-audit.yml:

.github/workflows/webmcp-audit.yml
name: WebMCP Quality Gate

on:
  pull_request:
    branches: [main]

jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npx playwright install --with-deps chromium
      - name: Audit Staging Server
        run: |
          npx webmcp-validator-cli scan https://staging.example.com \
            --fail-under 80 \
            --format markdown -o ./audit.md \
            --format sarif -o ./results.sarif
      - name: Append to GitHub Step Summary
        if: always()
        run: cat ./audit.md >> $GITHUB_STEP_SUMMARY
      - name: Upload Security Alerts
        uses: github/codeql-action/upload-sarif@v3
        if: always()
        with:
          sarif_file: results.sarif

📋 7. WebMCP Compliance Checklist (Grade A)

Follow this checklist to achieve an AI Readiness Score of 90+ (Grade A):

  • ✔
    Declarative Forms: HTML <form> tags include toolname, tooldescription, and toolaction attributes.
  • ✔
    Infrastructure: Delivered over HTTPS, HTTP 200 OK, response time under 1,500ms, and valid /robots.txt and /sitemap.xml.
  • ✔
    Agent Permissions: AI agent bots (GPTBot, ClaudeBot, etc.) are allowed; /llms.txt directives file present.
  • ✔
    Imperative JavaScript: navigator.modelContext.registerTool() configured with parameter schema and safe mutation hints (consequentialHint: true).
  • ✔
    Discovery Manifest: Accessible at /.well-known/webmcp containing valid JSON tool schemas.

❓ 8. Troubleshooting & FAQ

Q: Why does npx webmcp-validator return 404?
The registered package name on npm is webmcp-validator-cli. Use npx webmcp-validator-cli scan <url>. When installed globally via npm i -g webmcp-validator-cli, both webmcp and webmcp-validator work.
Q: How do I run this in Docker or a headless CI Linux server?
Install Chromium system dependencies using npx playwright install --with-deps chromium before running scans.
Q: How do I scan client-rendered React/Next.js pages?
The validator runs full headless Chromium and waits for network idle. If tools register late, increase the timeout using --timeout 20000.
